hetzner-node-watchdog is deployed and watching node Ready status in namespace {{ .Release.Namespace }}.

It matches Kubernetes nodes to Hetzner Cloud servers by name, and will restart
the server behind any node that stays unavailable for longer than
{{ .Values.config.timeoutDuration }} (--timeout-duration), waiting
{{ .Values.config.gracePeriod }} (--grace-period) after each restart before
trying again.

Check logs with:
  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "hetzner-node-watchdog.instanceFullname" (list . "primary") }} -f
{{- if .Values.secondary.enabled }}
  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "hetzner-node-watchdog.instanceFullname" (list . "secondary") }} -f

A secondary instance is also running, with timeoutDuration={{ .Values.secondary.config.timeoutDuration | default .Values.config.timeoutDuration }}
and gracePeriod={{ .Values.secondary.config.gracePeriod | default .Values.config.gracePeriod }}. It only acts if the primary itself is stuck or down.
{{- end }}

Only one replica per instance should ever run: restart scheduling is kept in
memory per pod with no leader election.
